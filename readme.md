🔥 Email Validator PRO

Aplicación profesional de validación masiva de correos electrónicos desarrollada en .NET 8 + WPF + MVVM.

Diseñada para marketers, developers y empresas que necesitan validar listas de emails de forma rápida, precisa y escalable.

🚀 Características Principales
✅ Validación individual y por lote
✅ Verificación de sintaxis (RFC básica)
✅ Verificación DNS de dominio
✅ Verificación de registros MX
✅ Validación SMTP en tiempo real
✅ Detección de emails desechables (tempmail)
✅ Detección de servidores Catch-All
✅ Detección de emails de rol (admin, info, support, etc.)
✅ Clasificación automática inteligente:
Valid
Invalid
Risky
Disposable
